# Changelog

## 2.0.0 (179)

Personal Tunnel written from scratch. No code from 1.x (the VPN Direct / sing-box for Apple fork) is left.

- New architecture: `TunnelKit` (platform-independent logic, tested on Linux in CI), a SwiftUI app, a slim packet tunnel and a WidgetKit extension; the Xcode project is generated by XcodeGen.
- Importers rewritten for share links, Base64 lists, Remnawave / Happ subscriptions with HWID, Xray JSON (including Xray 26 Hysteria with `finalmask` / `quicParams`), sing-box JSON, Clash YAML (own YAML reader) and WireGuard / AmneziaWG `.conf`. Unsupported protocols are reported by name.
- Configuration builder for sing-box 1.14: one selector over all servers of the active subscription, so switching servers while connected needs no reconnect.
- Ad blocking and the Russian bypass now run on rule sets built into the extension; nothing is downloaded at runtime.
- Own rules (always direct / always through VPN), DNS presets and custom DoH / DoT / DoQ / UDP, IPv6 switch.
- Latency test rebuilt on structured concurrency: two-stage primary mode, classic and alternative modes, instant cancel, memory-adaptive URL-test concurrency, unstable marks, connect to the best server.
- Three styles (Classic, Modern with iOS 26 Liquid Glass, Material You with a tonal palette and the cookie button), per-style accents, AMOLED, imported fonts, Russian and English switchable in the app.
- Analytics: two-minute speed chart, session and daily traffic, extension memory, routes and connections.
- Widgets on iOS 18: Home Screen and Lock Screen status with a button, Control Center toggle; Shortcuts and Siri phrases.
- Backups (reads 1.x `.ptbackup`), automatic local copy, keys excluded from device backups by default.
- First launch migrates 1.x profiles from `settings.db` or its automatic backup, keeps interface preferences and the HWID.

Not device-verified: written without Xcode, compiled by CI.
