# Настройки Personal Tunnel 3.5.20 — что есть сейчас

Список по коду, по порядку на экране. Номера — чтобы ссылаться при разметке («М3.2 убрать», «К5 перенести в…»).
Подписи под пунктами сокращены до сути; полный текст — в приложении.

## Минималистичный стиль

### М0. Корень «Настройки» (большой заголовок, 5 групп)

**Группа 1**
- М1. Внешний вид →
- М2. Язык →

**Группа 2**
- М3. Управление подписками →
- М4. Обновление подписок →

**Группа 3**
- М5. Подключение → (внутри и маршрутизация, и пинг)

**Группа 4**
- Блокировка приложения — переключатель прямо в корне
- М6. Резервные копии →
- М7. Конфиденциальность →
- М8. Сетевая активность приложения →

**Группа 5** (внизу — версия, например «3.5.20 (297)»)
- М9. Журнал службы →
- М10. О приложении →

Не в настройках, а на других экранах: «Порядок серверов» — в «…» списка серверов; «Проверка соединения» — внизу аналитики.

### М1. Внешний вид
1. Интерфейс: Современный / Классика
2. Оформление: Системная / Светлая / Тёмная
3. **Цвета**: Акцентный цвет · «Применить цвета» · «Сбросить цвета»
4. **Фон**: AMOLED — чёрный фон в тёмной теме · Свой фон
   - со «Своим фоном»: Цвет 1…4 · «Добавить цвет» · «Убрать последний цвет»
   - подпись: как раскладываются 2, 3, 4 цвета
5. **Текст и шрифт**: Цвет текста · Цвет панелей · «Применить цвет текста и панелей» · «Импорт шрифта TTF / OTF» · «Шрифт: …» · «Сбросить текст, панели и шрифт»
6. Панель серверов: Заголовок слева / Действия снизу / Поиск в шапке (+ подпись о трёх вариантах)
7. Стекло и прозрачность → (М1.9)
8. Только иконки вкладок · Акцентная активная точка

М1.9. **Стекло и прозрачность**
- Стекло: Чистое / Блюр / Tinted
- Непрозрачные панели настроек
- **Прозрачность стекла**: ползунки «Весь интерфейс», «Кнопка подключения», «Выбранный сервер»
- **Фон карточек** (карточки аналитики): Плотность фона (ползунок) · Цвет фона · «Сбросить фон карточек»

### М2. Язык
- Системный / Русский / English (подпись: системный — по языку iPhone)

### М3. Управление подписками
- «Добавить сервер или подписку» · «Обновить подписки»
- Для каждой подписки отдельная группа: N серверов · обновлена … · Действует до · Трафик (… из … / без лимита) · Передавать данные устройства провайдеру · «Обновить» · «Удалить»
- подпись: что получает провайдер при обновлении

### М4. Обновление подписок
- Автообновление подписок (переключатель)
- Время обновления: Каждые 24 часа / 00:00 … 23:00
- подпись: когда именно обновляются

### М5. Подключение (одна длинная страница из трёх частей)
**Без заголовка**
1. Автоподключение в неизвестных Wi-Fi
2. Мои сети → (М5.7)
3. подпись: как работает автоподключение
4. Kill switch + подпись (исключения iOS, больше батареи при видео, действует со следующего подключения)

**Маршрутизация и DNS**
5. Блокировка рекламы → (М5.8)
6. Обход российских сайтов + подпись
7. Без QUIC через VPN + подпись (новое, 3.5.18)
8. Защищённый DNS
9. Локальная сеть + подпись («Серверы DNS берутся из конфигурации…»)

**DNS вне туннеля**
10. Резолверы: Cloudflare и Google / Cloudflare / Google / Quad9 / Яндекс + подпись

**Пинг**
11. Режим пинга: Основной / Классика / Альтернативный + длинная подпись о выбранном режиме
12. подпись «Тест только показывает задержку…»
(«Автопинг» в этом стиле скрыт.)

М5.7. **Мои сети**: «Добавить текущую сеть …» (или «Текущая сеть … — в списке») · «Добавить сеть по названию» · **Сети** — список, нажатие удаляет

М5.8. **Блокировка рекламы**: переключатель + подпись · **Список**: Базовый / Стандартный / Расширенный (подпись о выбранном) · «Не пускать в обход блокировки» + подпись

### М6. Резервные копии
- «Сохранить копию в Файлы» · «Восстановить из файла» (подпись: копия содержит ключи, хранить как пароль)

### М7. Конфиденциальность
Почти вся страница — текст:
- Что приложение не собирает · Куда приложение подключается само · Что получает провайдер подписки
- **Передавать данные устройства провайдеру**: «Для новых подписок» + переключатель для каждой подписки
- Что хранится на iPhone · Журналы · Блокировка рекламы · Что видит провайдер VPN-сервера
- «Полный текст политики» → · «Удалить все данные» (красная)

### М8. Сетевая активность приложения
- Обновление подписок — по запросу · Проверка соединения — www.gstatic.com · Пинг серверов — URL-тест через сервер · HWID — xxxx…xxxx
- подпись: у приложения нет своего сервера

### М9. Журнал службы
Экран журнала: копирование, поиск, пауза, фильтр уровней.

### М10. О приложении
- Версия · Ядро · Xray-core · Ядро туннеля · Коммит · Группа (App Group) + подпись о лицензии

## Классика (одна прокручиваемая вкладка; разделы — рамки с заголовком капсом)

- К1. **ВНЕШНИЙ ВИД**: Интерфейс (Классика / Современный) · Тема (Системная / Светлая / Тёмная) · Цвета и шрифт → (= М1.3 + М1.5, без фона, AMOLED в «Цветах»)

## Что бросается в глаза (для обсуждения, не делаю без решения)

1. Стиль в коде и в документах — «Минималистичный», а в настройках он называется «Современный».
2. «Подключение» (М5) — одна длинная страница: автоподключение, kill switch, маршрутизация, DNS и пинг вместе.
3. Цвета применяются кнопкой «Применить…», а фон, стекло и переключатели — сразу.
4. «Конфиденциальность» — в основном длинный текст; переключатели передачи данных провайдеру есть и там, и в «Управлении подписками».
5. «Блокировка приложения» — единственный переключатель в корне, остальное — переходы.
6. В «Классике» «Порядок серверов» и «Проверка соединения» в настройках, в «Минималистичном» — на других экранах.
