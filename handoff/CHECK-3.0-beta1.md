# Что владелец проверяет в 3.0, beta 1 (212)

«Журнал службы» хранится в памяти приложения: строки приложения (`[app]`) пропадают, если его выгрузить
из памяти, а строки туннеля видны только при включённом VPN. Копирования в журнале нет — снимать экраном.
Поиск — лупа вверху журнала; фильтр — значок с полосками («Все»).

Где журнал: «Минималистичный» — Настройки → «Журнал службы» (третья группа); «Классика» — вкладка
настроек → «ДАННЫЕ» → «Журнал службы».

1. Версия: внизу настроек `3.0, beta 1 (212)`; «О приложении» → строка «Xray-core» (26.11.9).
2. Пропавшие Hysteria2: VPN выключен → обновить подписку (Минималистичный: «Серверы» → свайп по
   подписке → «Обновить»; Классика: меню подписки → «Обновить») → журнал, поиск `Подписка` и `Пропущен`.
3. Пинг без VPN: VPN выключен → кнопка пинга (Минималистичный: значок пульса в панели «Серверы»;
   Классика: стрелка на главной). Задержка у Hysteria2/TUIC/WireGuard? Журнал, поиск `Проверка задержки`
   (начало «… ядром приложения» и итог «ответили N из M») и `Ядро приложения`.
4. Автопинг: открыть приложение с выключенным VPN — пинг должен пойти сам (не чаще раза в 3 мин);
   переключатель: Минималистичный — Настройки → «Сеть и безопасность» → «Автопинг»; Классика — вкладка
   настроек → «ИЗМЕРЕНИЕ ЗАДЕРЖКИ» → «Автопинг».
5. Память: подключить VPN → журнал, поиск `[mem]`: строка сразу и далее раз в минуту; снять через 1 и
   через 10 мин работы (с YouTube/браузером), для сравнения то же на 2.0.4, если она ещё стоит.
6. Падение: если VPN сам отключился — при следующем открытии экран «Туннель завершился аварийно» →
   «Поделиться журналом» (адреса и ключи вырезаны).
