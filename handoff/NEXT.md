# Следующая сессия: 3.0, beta 3 (215) на устройстве владельца

## Beta 3 (215): что сделано по отзыву на beta 2

- Серверы Xray подключались с моментальной ошибкой: `command.sock` отсутствовал, пик памяти сбросился —
  расширение, похоже, падало. Сделано: каждое звено Xray, которое само выходит в сеть, привязано к
  физическому интерфейсу (`sockopt.interface`, как sing-box привязывает свои), перезапуск Xray при смене
  сети, буферы 4 КБ; журнал Xray (`Working/xray.log`) и последнее падение ядра (`crash_reports/*/go.log`)
  попадают в «Скопировать всё». Причина не подтверждена — ждём журнал с устройства.
- «АНТИЖАЛОСТИ»: панель отдаёт полный список (с Hysteria) только Incy; без HWID — заглушка «приложение не
  поддерживается». Подписки запрашиваются как `INCY/2.7.2` (с HWID), затем Happ, затем обычный клиент;
  заглушка → следующий клиент (`SubscriptionStub`). Ошибки обновления у владельца: без VPN адрес подписки
  недоступен, с VPN был выбран сломанный сервер Xray.
- Свайп: символы белые всегда, капсула тёмно-серая до конца жеста. «+»: лист привязан к кнопке (на iOS 26
  уезжал за верх экрана), новые пункты «Отсканировать QR» и «Создать вручную». «Редактировать» открывает
  ту же форму (`ServerDraft` в TunnelCore с тестами; группы и серверы Xray — только переименование).
- Журнал: новые строки сверху, открывается сверху, карточка над панелью вкладок.


Ветка `claude/xray-core-client-3-0-6jncfl`. Всё ниже собрано и проверено тестами на Linux и сборкой в CI;
на устройстве владелец проверил только сборку 213 (подключение, память).

  (sing-box + Xray-core + мост, Go 1.27.4). Владелец выбрал общую — `TUNNEL_CORE=combined` по умолчанию,
  CI собирает только её (вариант `singbox` остаётся в `scripts/build-libbox.sh` и матрице для сравнения).
  Почему не подключалась бета 1 (212) — не выяснено: та же библиотека в 213 работает.
- Память расширения: sing-box ≈ 17 МиБ на старте, 27–29 МиБ под нагрузкой; общая — ≈ 19 МиБ на старте.
- Пинг с VPN давал «нет маршрута»: TCP-проверка в обход туннеля на iOS 27 не проходит. Исправлено (см. ниже).
- В ALL VPN 192 + 21 пропущенный (`header-custom`, `sudoku`) = 213 — все. В «АНТИЖАЛОСТИ» 36 из ~68:
  провайдер, видимо, отдаёт Happ урезанный Xray JSON — добавлена догрузка обычного списка.

## Что в 3.0, beta 2 (214)

- Приложение и расширение — каждое со своей библиотекой (`AppCore.xcframework` / `Libbox.xcframework`).
- **Серверы только для Xray**: сервер, который sing-box не понимает, хранится как outbound типа `xray`
  (его исходные outbounds Xray). sing-box ходит к нему через `socks` на 127.0.0.1:20800+i, Xray-core
  (`ptbridge.StartXray`) в расширении слушает эти порты (`tunnel-xray.json` в группе, пишет
  `LibraryStore.writeActiveConfig`). Приложение для пинга поднимает свой Xray на 30800+500·k.
  Сквозной тест в CI: Xray-сервер с маской `sudoku` ← наш Xray ← sing-box (`core/bridge/e2e_test.go`).
  Серверы появятся после обновления подписки.
- **Пинг**: серверы подключённой подписки — URL-тест через расширение без TCP-фильтра; остальные
  подписки (и всё без VPN) — ядро приложения; с VPN их задержка включает туннель. Первые 3 ошибки
  прогона пишутся в журнал словами ядра.
- **Догрузка серверов**: подписка в формате Xray JSON догружается обычным клиентом, недостающие
  серверы добавляются (`SubscriptionMerge`).
- **Журнал**: «Скопировать всё» (+ события расширения), без цветовых кодов; адреса серверов
  владельца и их IP скрываются (`Redactor.hideServers`); строки приложения не пропадают при
  переподключении ядра. Память расширения — в «Проверке соединения».
- **Панель «Серверы»**: меню удержания как в 1.5.0, «Выбрать несколько», «Ссылка, QR и JSON»,
  скруглённая подсветка, разгруженная прокрутка, свайп вниз после сворачивания.
- **Блокировка рекламы**: страница в настройках обоих стилей; Базовый / Стандартный (HaGeZi Light,
  по умолчанию) / Расширенный (HaGeZi Normal); DNS отвечает 0.0.0.0 / ::.
- Автопинг скрыт (`Prefs.autoPingAvailable = false`).

## Не сделано / открыто

- Список рекламных IP — отказались (нет поддерживаемого списка, ложные блокировки на CDN).
- Xray-сервер с балансировщиком внутри (несколько прокси) идёт через первый прокси.
- Из списка 2.0: QR-сканер, «Обои», чтение резервных копий 1.x, редактор сервера (только
  переименование), «Автоматический failover», Пункт управления.
