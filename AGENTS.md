# Personal Tunnel — рабочие заметки

Клиент VPN для iPhone на ядре sing-box (форк sing-box-lx, закреплён в `core/VERSION`). Версия 2.0 написана
с нуля. Главный документ задачи — `handoff/BRIEF.md`; скриншоты и записи 1.5.0 лежат рядом.

## Правила

- Интерфейс обоих стилей («Классика» и «Минималистичный») должен совпадать с 1.5.0: записи экрана в
  `handoff/recordings` и исходники 1.5.0 — эталон. Скриншоты `handoff/screenshots` сняты на более старой
  сборке; при расхождении верны записи и исходники. Каждое существенное отступление сначала предложить владельцу.
- Код 1.x (ветка `claude/personal-tunnel-visual-refactor-eiz8j9`, бандл) не переносить. Из него берутся только
  тексты, порядок пунктов, поведение, ключи настроек и формат данных.
- Отвергнутая попытка 2.0 (`claude/personal-tunnel-rewrite-eejfi1`): один набор экранов SwiftUI с палитрами
  вместо двух настоящих стилей. Не повторять: у каждого стиля свои экраны поверх общего ядра.
- Общение с владельцем на русском. Интерфейс: русский и английский. Русский текст — ключ: в коде `L("…")` / `Lf("… %@", …)`, в ядре `CoreText.t` / `CoreText.f`; перевод в `App/Resources/en.lproj/Localizable.strings`. Новая строка интерфейса добавляется туда же с переводом.
- Ключи `UserDefaults` 1.x (`personal.*`), Keychain-запись HWID и App Group сохраняются: по ним 2.0
  подхватывает настройки и данные. Не переименовывать.
- Никогда не помещать ссылки подписок, ключи и адреса серверов владельца в код, журналы, тесты и коммиты.
  Текст, уходящий из приложения, пропускается через `Redactor`.
- Не писать, что что-то проверено на устройстве, если это только собралось в CI.

## Устройство

- `Packages/TunnelCore` — только Foundation, собирается на Linux. Любое изменение разбора или конфигурации
  сопровождается тестом; образцы в `Sources/tunnelcore-fixtures` проверяются в CI закреплённым ядром.
- `App` — UIKit, минимальная iOS 16. Жидкое стекло только с iOS 26, ниже — системное размытие. Состояние
  разбито на мелкие хранилища; секундный таймер обновляет только подписи сеанса и трафика; результаты пинга
  применяются пачками.
- `PacketTunnel` — расширение с Libbox. Держать маленьким: лимит памяти около 50 МиБ.
- Проект генерирует XcodeGen из `project.yml`; локально компилятора iOS нет, компиляцию проверяет CI.

## Версия

`Config/Base.xcconfig`: `MARKETING_VERSION` и `CURRENT_PROJECT_VERSION` (номер сборки только растёт).

Правило владельца для `MARKETING_VERSION` (x.y.z), с каждой новой сборкой для него:
- небольшие изменения и исправления — третье число: 2.0.1, 2.0.2, 2.0.3…;
- значительные изменения — второе число: 2.1, 2.2…;
- первое число — только полная переработка, обсуждается с владельцем отдельно.
- Бета: `MARKETING_VERSION` не меняется (3.0), растут номер беты (`BETA_NUMBER`) и номер сборки:
  «3.0, beta 1 (212)», «3.0, beta 2 (214)»… Диагностическая сборка между бетами — тот же номер беты,
  новый номер сборки.
