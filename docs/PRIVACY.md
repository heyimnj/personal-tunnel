# Политика конфиденциальности Personal Tunnel

Действует с версии 2.0.0. Описание составлено по коду; если код и текст расходятся, верен код.

## Коротко

- Нет аккаунтов, оплаты, рекламы, аналитики и отчётов о сбоях. У приложения нет своего сервера.
- Само приложение выходит в сеть только в трёх случаях: обновление подписок, проверка соединения (по кнопке) и проверка задержки серверов. Каждый такой запрос записывается в «Настройки → Сетевая активность приложения».
- Ваш трафик идёт через серверы, которые добавили вы.

## Обновление подписки

Запрос на ссылку подписки (`TunnelKit/Subscription/SubscriptionFetcher.swift`). Первый запрос идёт с User-Agent `Happ/3.13.0`; если для подписки включена отправка данных устройства (по умолчанию), к нему добавляются:

| Заголовок | Значение |
|---|---|
| `X-HWID` | идентификатор, созданный один раз из `identifierForVendor`; не связан с Apple ID |
| `X-Device-OS` | `iOS` |
| `X-Ver-OS` | версия iOS |
| `X-Device-Model` | модель, например `iPhone16,2` |
| `X-Device-Locale` | язык и регион |

Если панель не приняла ответ, запрос повторяется с другими User-Agent и без данных устройства. При переадресации на другой адрес идентифицирующие заголовки удаляются, переход с HTTPS на HTTP запрещён. Отправку выключают для каждой подписки: «Подписка → Изменить → Отправлять HWID…»; там же показаны заголовки.

## Проверка соединения

`GET https://www.gstatic.com/generate_204` — только по нажатию кнопки «Проверить».

## Проверка задержки

TCP-соединение с адресом и портом сервера в обход VPN, без передачи данных, и (если VPN включён) запрос `generate_204` через сам сервер средствами ядра.

## Ядро VPN

Ядро sing-box выполняет то, что задаёт конфигурация: DNS-запросы через выбранный сервер (или на ваш DNS), разрешение адресов серверов и российских доменов системным DNS. Блокировка рекламы и списки обхода встроены в приложение и не скачиваются.

## Что хранится на устройстве

| Данные | Где | Копия iPhone/iCloud |
|---|---|---|
| Подписки, серверы с ключами | `library.json` в App Group | нет, пока включено «Не сохранять ключи в копии iPhone/iCloud» (по умолчанию) |
| Конфигурация для запуска туннеля | `Tunnel/active-config.json` в App Group | так же |
| Автокопия | `Documents/PersonalTunnelRecovery` | так же |
| HWID | Keychain (только это устройство) | нет |
| Журнал сетевой активности (до 200 записей, значения замаскированы) | настройки App Group | да |

Журнал ядра хранится в памяти, пока открыт экран, и при копировании проходит через `Redactor`: ссылки, UUID, пароли, ключи и длинные идентификаторы скрываются.

Файл резервной копии, который вы сохраняете сами, содержит ссылки подписок и ключи серверов в открытом виде.
